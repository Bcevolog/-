# 需求文档

## 1. 应用概述

### 1.1 应用名称
财报速读工具

### 1.2 应用描述
一款面向投资者的轻量级财报速读Web应用。用户上传上市公司财报PDF文件后，系统调用AI大模型进行解析，生成核心财务结论及同比变动分析，并提供AI问答窗口支持针对财报内容的进一步交互咨询。

## 2. 用户与使用场景

### 2.1 目标用户
个人投资者、证券分析师及需要快速了解上市公司财务状况的办公人群。

### 2.2 核心使用场景
- **财报快速提炼**：用户上传当期财报PDF，快速获取收入、利润、现金流、风险点四维核心结论及去年同期对比。
- **深度互动提问**：针对速读结论或财报细节，通过页面内AI聊天窗口进行追问。

## 3. 页面结构与功能说明

### 3.1 页面结构

```text
财报速读主页
├── 文件上传区
├── 速读结论展示区
│   ├── 收入分析及同比
│   ├── 利润分析及同比
│   ├── 现金流分析及同比
│   └── 核心风险点
└── AI 聊天问答窗口
```

### 3.2 功能说明

#### 3.2.1 财报速读主页
- **文件上传区**：
  - 提供财报PDF文件选择与上传入口。
  - 上传完成后触发AI分析流程并展示解析进度状态。
- **速读结论展示区**：
  - 展示四行核心分析结论：
    1. **营业收入**：展示本期数值及与去年同期对比变动。
    2. **净利润**：展示本期数值及与去年同期对比变动。
    3. **现金流**：展示本期经营活动现金流等核心数据及与去年同期对比变动。
    4. **核心风险点**：提炼财报中披露的重要潜在风险与异常点。
- **AI 聊天问答窗口**：
  - 提供内嵌对话小窗口。
  - 用户输入针对当前财报的问题，系统结合已上传财报内容调用AI大模型返回解答。
  - 支持查看当前会话的历史问答记录。

## 4. 业务规则与核心逻辑

1. **AI 解析流程**：用户上传PDF后，系统调用AI大模型API提取当期与去年同期核心财务指标及风险提示，生成速读结论。
2. **上下文关联**：AI聊天窗口默认以当前已解析的财报文本为知识上下文，解答用户提问。
3. **单文档分析**：单次解析以当前最新上传的PDF为准，重新上传文件将更新速读展示区并重置聊天上下文。

## 5. 异常与边界情况

| 场景 | 异常情况 | 处理规则 |
| :--- | :--- | :--- |
| 文件格式错误 | 用户上传非PDF格式文件 | 提示仅支持上传PDF格式文件并阻止提交 |
| 大模型解析失败 | AI接口响应异常或解析超时 | 提示解析失败，并允许用户重试 |
| 内容无法提取 | PDF为纯图片/扫描件无文字信息 | 提示无法识别文字内容，建议上传文字版财报 |

## 6. 验收标准

1. 用户在公网环境下可通过浏览器成功访问应用页面。
2. 用户上传一份上市公司财报PDF文件后，系统能在30秒左右完成解析并展示收入、利润、现金流、风险点四行结论及同比数据。
3. 用户在AI聊天小窗口中发送关于该财报的提问，系统能基于财报内容给出合理答复。
4. 重新上传新财报后，速读结论与问答上下文同步更新为新财报内容。
